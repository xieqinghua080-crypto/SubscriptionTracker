# 订阅追踪 — 支持

一款纯本地的订阅管理工具：记录每月 / 每年自动扣款的订阅，提前提醒，统计支出。

## 常见问题

**Q: 我的数据会被上传到服务器吗？**
A: 不会。所有订阅数据只保存在你的 iPhone 本地（`Application Support/subscriptions.json`）。App 不联网、不需要登录，也不含任何广告或第三方统计 SDK。

**Q: 扣款提醒是怎么发出的？**
A: 使用 iOS 本地通知，默认在扣款日前 7 天提醒你。整个过程不需要网络，也不需要注册账号。

**Q: 支持哪些扣款周期？**
A: 月付、年付，以及自定义周期。

**Q: 删除 App 后数据还在吗？**
A: 数据随 App 一起删除。重要的订阅建议你另行记录备份。

**Q: 为什么不需要登录？**
A: 因为所有数据都在你设备本地处理，没有云端账户，所以无需登录。
